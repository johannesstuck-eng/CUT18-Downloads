# CUT18 Downloads

Official public installers for CUT18 — the golf video editing playbook.

## Download

Use the [latest GitHub release](https://github.com/johannesstuck-eng/CUT18-Downloads/releases/latest) and select the installer for your operating system:

- Windows x64: `.exe`
- macOS Apple Silicon: `mac-arm64.dmg`
- macOS Intel: `mac-x64.dmg`

Published builds are currently unsigned test versions. Verify downloaded files with the included `SHA256SUMS.txt`.

This repository contains release artifacts only. Product source code, development issues, and pull requests are maintained privately.
